# CraveBite 🍔

A responsive food delivery storefront built with plain HTML, CSS and JavaScript. No framework, package installation or build step required.

## Features
- Responsive desktop and mobile layout
- Food categories and live search
- Add-to-cart and quantity controls
- Subtotal, delivery fee and total calculation
- Demo checkout (no real payment or order processing)
- Coupon code copy interaction

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

Optional: use the VS Code **Live Server** extension for a local development server.

## Deploy to Vercel
1. Create a new repository on GitHub and upload all files in this folder.
2. Open [Vercel](https://vercel.com/) and sign in with GitHub.
3. Click **Add New → Project**, then import your CraveBite repository.
4. Keep Framework Preset as **Other**.
5. Keep the Root Directory as `./` and leave Build Command and Output Directory empty.
6. Click **Deploy**. Vercel will provide your live website URL.

## Important
This is a front-end demo. Cart data is held in browser memory and resets on refresh. Checkout is simulated; no orders, payments, accounts or delivery tracking are connected. Food photos are loaded from Unsplash and Google Fonts are loaded online.
